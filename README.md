# NLP ШИФТ: Классификация банковских интентов на базе ruBERT

## Задача

1) Создать синтетический набор данных используя открытую LLM для решения поставленной задачи
2) Обучить модель классификации текста на основе созданного набора данных используя трансформерную модель энкодер (например BERT)

## В этом репозитории можно посмотреть/скачать
* `NLP_ШИФТ.ipynb` — единый Jupyter-ноутбук, содержащий обе части проекта (генерацию данных, EDA, обучение ruBERT и демо-инференс).
* `synthetic_dataset.jsonl` — итоговый датасет (1500 примеров, 15 классов по 100 сэмплов).

## Часть 1. Генерация данных (Data Engine)
Для создания обучающего корпуса использовалась связка локальной языковой модели **Qwen2.5-14B-Instruct** (запущенной через `llama.cpp` на GPU в Google Colab) и скрипта `data_engine.py`. 

* **Особенности генерации:**
  - Строгий контроль структуры: каждый пример представляет собой диалог ровно из 3 реплик (`user -> assistant -> user`).
  - Фокус на последней реплике: класс (интент) определяется исключительно финальным вопросом пользователя.
  - Структурированный вывод (Structured Outputs) через Pydantic-модели для гарантии валидности JSON.
  - Дедупликация и потоковая запись в `jsonl`.

### Таксономия (15 банковских классов):
1. `transfer_status` — статус или задержка перевода.
2. `card_block` — срочная блокировка карты.
3. `loan_early_repayment` — досрочное погашение кредита.
4. `app_error` — сбои в мобильном приложении.
5. `card_order` — заказ новой или дополнительной карты.
6. `loan_application` — оформление заявки на кредит.
7. `atm_location` — поиск банкоматов и отделений.
8. `balance_info` — проверка баланса и остатка.
9. `transaction_history` — история операций и выписки.
10. `pin_change` — смена или восстановление ПИН-кода.
11. `theft_report` — мошеннические списания и кражи.
12. `currency_exchange` — курсы валют и конвертация.
13. `sbp_payment_issue` — проблемы с переводами через СБП.
14. `card_reissue` — перевыпуск карты по истечении срока.
15. `feedback_complaint` — отзывы и жалобы.

## Часть 2. Обучение классификатора (Fine-tuning ruBERT)
В качестве базовой модели использовался энкодер `ai-forever/ruBert-base`. 

* **Параметры обучения:**
  - Датасет: 1200 train / 300 test (стратифицированный сплит 80/20).
  - Максимальная длина последовательности (`max_length`): 64 токена.
  - Эпох: 5, learning rate: `2e-5`, batch size: 16/32.
  - Оптимизатор: AdamW, метрика для выбора лучшей модели: `F1-macro`.

### Итоговые метрики на тестовой выборке:
* **Accuracy:** `0.9800` (98.0%)
* **F1-macro:** `0.9801`
